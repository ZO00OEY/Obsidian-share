
> [!summary]
> 这是一个用 Gemini 交互生成 `p5.js` 动态艺术图的案例。目标效果是“飞鸟蒲公英”：深蓝星空背景，一朵蒲公英由大量浅蓝飞鸟组成，飞鸟按黄金角螺旋排布并逐渐飞散。完整流程是：问答 AI 拆需求 -> 专业代码 AI 写 `p5.js` -> 在线网站运行预览 -> 手机剪辑工具做成动态图片。

## 项目目标

- 作品名：飞鸟蒲公英。
- 技术方向：`p5.js` 创意编程。
- 画布：`600 * 800`。
- 画面：深蓝星空背景，中心是一朵蒲公英，蒲公英绒毛由很多小飞鸟组成。
- 动态：花茎轻微左右摆动，飞鸟展开翅膀，并从蒲公英上脱离、向右上方飞散。
- 调整方式：第一次生成不理想时，继续用自然语言追加反馈，让 AI 修改代码参数和逻辑。

## 第一次指令

```text
请使用 p5.js 编写一个创意编程作品：“飞鸟蒲公英”。请遵循以下详细规格：

视觉风格：
背景：600 * 800 深蓝色（#3168B5）画布，并叠加大量微小的半透明白色像素点，营造出一种带有颗粒感的深夜星空质感。

主体：一朵由约 350 只极小飞鸟组成的蒲公英。飞鸟颜色为浅天蓝（#D2E9FF），带有浅蓝色的柔化外发光（#A0CFFF88）效果。

核心与花茎：蒲公英中心是一个发光的粉红色圆球（#F49B9B）。花茎是一条墨绿色（#84A56F）的曲线，连接中心到底部。

代码规范：
请将所有可能会修改的参数全部提取到代码最顶部的 // === 配置参数区 ===，不要将数字硬编码在底层逻辑中，并添加详细正规的注释。代码需要模块化，使用 ES6 Class 面向对象编程。
```

## 第二次指令：数学分布

```text
数学分布（核心）：
请使用 Vogel's Phyllotaxis（黄金角分布）公式来排列这 350 只飞鸟，使其形成一个完美的自然螺旋圆形。
角度间隔应基于黄金角（约 137.5 度）。
```

用途：

- 解决“随机散点不像蒲公英”的问题。
- 用黄金角让飞鸟自然排布成螺旋结构。
- 让作品从“很多小鸟”变成“蒲公英绒球”。

## 第三次指令：动态逻辑

```text
动态效果：
整体摇曳：利用正弦函数（sin）让花茎和整朵花产生左右平滑的摆动。

翅膀扇动：通过在水平方向上微调飞鸟的缩放比例（scale），模拟它们正在扇动翅膀的视觉错觉。

飞散逻辑：设定一个延迟，之后飞鸟开始从蒲公英上脱离，集体向右上方（约 -45 度方向）飞去。

飞行物理：飞鸟起飞时应具有随机的延迟（不要同时起飞）。飞鸟的头部必须实时指向其运动的合成速度方向。
```

用途：

- `sin` 负责整体柔和摆动。
- `scale` 负责模拟飞鸟拍翅膀。
- 随机延迟负责避免所有飞鸟同时起飞。
- 速度方向决定飞鸟朝向，避免飞鸟“横着飘”。

## 第四次指令：替换飞鸟素材

```text
飞鸟使用提供的 svg 代替简易飞鸟，飞鸟大小可进行缩放，并且随机大小打破视觉上的单一感和僵硬感，让画面看起来更灵动，营造空间深度。
在飞离前飞鸟不要煽动翅膀。

ps: svg 图片可自行搜索，也可提供给 AI 其他透明格式图片，自行选择。
```

关键点：

- 不满意默认飞鸟时，直接让 AI 使用 SVG 或透明图替换。
- 飞鸟要支持缩放和随机大小。
- 用随机尺寸制造空间深度。
- 起飞前不扇动翅膀，减少画面杂乱。

## 不理想时的微调话术

```text
如果飞得太整齐：增加起飞时间的随机范围。
如果主茎太细：主茎长度宽度可调整设置。
如果蒲公英整体占比过高：整个蒲公英的大小可缩放调整。
```

这类反馈不用重新写完整 prompt，直接指出视觉问题和想改的方向即可。

## 工作流复盘

1. 先用问答 AI 把画面拆成视觉规格、数学分布、动态逻辑和可调参数。
2. 再让专业代码 AI 生成 `p5.js` 代码。
3. 放到在线 `p5.js` 网站运行预览。
4. 根据画面问题继续追加自然语言反馈。
5. 最后用手机剪辑工具录屏或处理成动态图片。

## 可复用 Prompt 骨架

```text
请使用 p5.js 编写一个创意编程作品：“作品名”。

视觉风格：
- 画布尺寸、背景色、颗粒/光效/质感。
- 主体由多少个基础元素组成，元素颜色、发光、大小范围。
- 中心、连接结构、辅助元素的颜色和形状。

数学分布：
- 使用某种自然分布或几何公式排列元素。
- 指定角度、间距、半径、密度等核心参数。

动态效果：
- 整体运动方式。
- 单个元素的局部动画。
- 元素离散、聚合、飞散或变形逻辑。
- 随机延迟、速度方向、朝向更新等物理细节。

代码规范：
- 将所有可调整参数集中到顶部 CONFIG。
- 不要硬编码关键数字。
- 添加清楚注释。
- 使用模块化结构和 ES6 Class。
```

## 经验结论

- 这类效果的关键不是一句 prompt，而是把“视觉、数学、动态、参数、素材”拆开逐轮喂给 AI。
- 第一版不理想很正常，后续微调要说具体视觉问题，例如太整齐、太细、占比过高。
- 动态艺术项目最好保留 `CONFIG` 参数区，后面调尺寸、速度、密度会轻很多。
- 用 SVG 或透明素材替换简笔图形，是提升完成度最快的一步。
